# Sharda Foundation Official Website

The official website for **Sharda Foundation**, a non-profit society dedicated to promoting excellence in medical research, providing aid to underserved patients, and enhancing medical education.

🔗 **Live Demo:** [https://sharda-foundation.onrender.com](https://sharda-foundation.onrender.com)

##  About the Project

This website serves as the digital presence for the Sharda Foundation, located in Jabalpur. It showcases the society's three core pillars:
1.  **Medical Research:** Developing low-cost healthcare innovations.
2.  **Patient Support:** Organizing free medical camps and providing financial aid.
3.  **Education:** Conducting CMEs and workshops for healthcare professionals.

##  Features

* **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop.
* **Modern UI:** Clean, medical-themed interface using a Deep Teal & Sage Green color palette.
* **Donation Gateway:** Integrated UPI QR code modal for instant donations.
* **Mobile Navigation:** Custom hamburger menu for mobile users.
* **Lightweight:** Built with static HTML/CSS for ultra-fast loading speeds (no database required).

##  Tech Stack

* **Frontend:** HTML5, JavaScript (Vanilla)
* **Styling:** Tailwind CSS (via CDN)
* **Hosting:** Render (Static Site)
* **Version Control:** Git & GitHub
